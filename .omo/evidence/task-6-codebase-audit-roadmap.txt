9. Toolchain note
================================================================================
rust/rust-toolchain.toml pins channel = "1.75". In this container the 1.75
toolchain's rust-std component download failed ("Directory not empty" / "No
such file or directory" rename errors). The 1.75 build cannot be exercised
here without network/disk intervention. All build/test/audit commands were
run with `+stable` (rustc 1.97.1) instead, which is what the host toolchain
is. The deprecation warning on `rand::thread_rng` is a rand 0.9 change
visible in both 1.75 and 1.97, so the rand 0.8 -> 0.9 verdict does not
depend on which toolchain runs the build. The crate's API surface in rand
0.9 (SliceRandom, thread_rng, shuffle) is identical between 1.75 and 1.97;
only the deprecation lint message exists on both.
