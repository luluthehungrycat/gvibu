# sum(1) — gvibu

## NAME

**sum** — Compute BSD 16-bit checksum and block count (1024-byte blocks) for each file

## SYNOPSIS

`gvibu sum [OPTIONS] [ARGS...]`

## DESCRIPTION

Compute BSD 16-bit checksum and block count (1024-byte blocks) for each file.

## EXIT STATUS

- `0`: Success
- `1`: Missing operand or file error
